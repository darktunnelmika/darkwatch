# Bundled terminal frontend dependencies

These JavaScript and CSS assets are included locally so the terminal works even when CDN sites are unavailable:

- `app/static/vendor/xterm.js`: xterm.js from the Jupyter nbclassic distribution (MIT license, xterm.js authors and contributors; portions originally by Christopher Jeffrey / term.js)
- `app/static/vendor/xterm-fit.js`: xterm.js fit addon from the same distribution (MIT license)
- `app/static/vendor/xterm.css`: xterm.js terminal styles from the same distribution (MIT license)

Project website: https://xtermjs.org/ . Project license: https://github.com/xtermjs/xterm.js/blob/master/LICENSE . The deployed app contains no CDN dependencies.
