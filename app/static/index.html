// QUICK START / SECURE CONNECTIONS

راهنمای اتصال SSH

برای افزودن سرور جدید به نصب Agent نیازی نیست

01

کلید عمومی پنل مرکزی

بعد از نصب، روی سرور مرکزی دستور زیر را اجرا کن و خروجی کلید عمومی را بگیر:

sudo cat /var/lib/darkwatch/.ssh/id_ed25519.pub
02

مجوز اتصال به سرور مقصد

کلید عمومی مرحله قبل را در فایل زیر روی سرور مقصد قرار بده:

~/.ssh/authorized_keys

اگر از root استفاده می‌کنی، کلید را در پوشه SSH کاربر root ثبت کن. برای امنیت بیشتر کاربر محدود پیشنهاد می‌شود.

03

تأیید اثرانگشت سرور

اثر انگشت SSH مقصد را از یک مسیر امن بررسی کن، سپس کلید میزبان را به known_hosts کاربر darkwatch اضافه کن. جزئیات دستورها در README آمده است.

/var/lib/darkwatch/.ssh/known_hosts
04

افزودن سرور در پنل

IP، پورت SSH و نام کاربری را وارد کن؛ پس از برقراری اتصال، نمودارها به‌صورت خودکار فعال می‌شوند.

🔒 پنل به‌طور پیش‌فرض فقط روی localhost باز می‌شود. برای دسترسی از بیرون از تونل SSH یا HTTPS استفاده کن. تأیید کلید میزبان SSH هرگز خودکار غیرفعال نمی‌شود.
